# Full-Box Damage Images

One dataset folder containing three class folders and 600 JPEG images. There are no train, validation, or test splits.

- `scratch/scratch_001.jpg` through `scratch/scratch_200.jpg`
- `dent/dent_001.jpg` through `dent/dent_200.jpg`
- `tear/tear_001.jpg` through `tear/tear_200.jpg`

Every source image was generated with the entire closed sneaker box, including the lid, base, edges, and corners, visible inside the frame.

See `full_box_damage_manifest.csv` for labels and provenance and `full_box_damage_audit.json` for validation results.
