# Impeccable Design Context

## Design Context

### Users
Sneakerhead resellers — StockX/GOAT sellers photographing sneaker boxes before listing. Context: garage/closet inventory sessions, often at night, phone in one hand, box in the other. Job to be done: "tell me fast if this box damage tanks my resale price." Secondary audience: demo-day judges (school project) — first impression must land in seconds.

### Brand Personality
Hype streetwear. Bold, loud, sneaker-drop energy. Confident, a little cocky, zero corporate softness. Three words: **hyped, decisive, street**. Emotional goal: the verdict should feel like a sneaker-drop reveal — anticipation during scan, punch at the result.

### Aesthetic Direction
Dark theme (garage/night context; verdict colors punch harder on dark). Big condensed display type, high contrast, poster-like compositions. References: SNKRS drops, StockX condition tags, streetwear lookbooks, boxing-match tale-of-the-tape graphics. Anti-references: corporate dashboards, medical-app softness, generic Material defaults, AI-slop gradient-on-dark.

### Design Principles
1. **Verdict is the hero** — Low/Caution/High reveal is the product's dunk moment; everything builds to it.
2. **Poster, not dashboard** — each screen composed like a drop poster: one dominant element, asymmetric, big type.
3. **Evidence earns trust** — bounding boxes, cm measurements, confidence % styled like spec sheets/tale-of-the-tape, not clinical tables.
4. **Fast hands** — one-thumb flows, huge tap targets, no modal detours.
5. **Dark with intent** — near-black tinted surfaces, rare sharp accents; no neon-purple AI slop.

### Overdrive Decisions (confirmed)
Copy: straight talk, shorter/punchier — verdict word + damage fact ("HIGH RISK · tear ~9.2 cm" — tilde because sizes are estimates from nominal box dimensions), no advice lines, no slang. Restraint rule: near-monochrome dark; verdict color only on result banner + history tags; no decorative shapes/dividers/cards.
- **P0 The Reveal**: analyzing screen runs FragmentShader scan-line sweep over captured photo (chromatic displacement near damage bboxes via uniforms) → 300ms hold → verdict banner spring-slams in + haptic → bboxes self-draw staggered (~80ms) → spec rows fade up. Reduced-motion: plain fade sequence.
- **P1 The Feel**: hero morph of photo from history tile → result screen; spring (ease-out-quint+) curves everywhere; optimistic saves; no reveal re-animation on history revisit.
- **P2 The Scanner**: corner-bracket box guide "breathes" ("whole box in frame" — sizing comes from the box itself, no reference card); edge-glow when a box-like quad is in frame (cheap luminance heuristic, feature-flagged); mechanical shutter snap + haptic. Degrades to static brackets (emulator/no-camera path unaffected).

### Platform Note
App is Flutter (Material 3 base, heavily customized). Web-CSS specifics from impeccable references translate to Flutter equivalents (OKLCH → Color tokens picked at equivalent lightness/chroma; type scale via TextTheme; motion via implicit/explicit animations with ease-out curves).
